# System Overview

The project is an Arduino-based autonomous robot capable of:
- Detecting fire
- Avoiding obstacles
- Navigating automatically
- Spraying water to extinguish flames

- Arduino Uno

- Ultrasonic Sensor

# 🎯 Objective

To design a low-cost autonomous robotic system that improves fire safety and reduces human risk in hazardous environments.
