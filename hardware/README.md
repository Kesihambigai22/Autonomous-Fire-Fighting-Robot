# 🧰 Hardware Details

This section describes the hardware components used in the Autonomous Fire-Fighting Robot.

---

## 🔌 Components Used

- Arduino Uno (Microcontroller)
- Flame Sensor (Fire detection)
- Ultrasonic Sensor HC-SR04 (Obstacle avoidance)
- L298N Motor Driver
- DC Motors with wheels
- Servo Motor
- Water Pump
- Battery (7.4V–12V)

---

## 🔗 Working Connections

- Flame sensor → Arduino analog pin  
- Ultrasonic sensor → Trigger & Echo pins  
- Motor driver → Arduino digital pins  
- Servo motor → PWM pin  
- Pump → Controlled via relay/module  

---

## ⚡ Power Supply

- Battery used to power motors and pump  
- Voltage regulator provides stable 5V to Arduino and sensors  

---

## 🧠 Note

The hardware is designed to be compact, low-cost, and easily replicable for educational purposes.
